# Personal Fitness Tracker AI Assistant

## Overview

A web-based fitness tracker that uses AI to give personalised guidance. The app lets users log activity, set goals, and receive intelligent recommendations — while being safe, honest about its limitations, and easy to use for anyone.

---

## Features

### 1. User Profile Setup
Collect the user's name, age, and fitness goal (e.g. lose weight, build strength, stay active).

### 2. Workout / Activity Log
Let users record what they did, for how long, and how it felt.

### 3. AI Recommendations
Use Claude to suggest next steps based on the user's profile and activity log.

### 4. Progress View
Show the user what they've done so far (even a simple list is acceptable).

### 5. Safety Guardrail
At least one check that prevents harmful or unrealistic advice (e.g. extreme diets, unrealistic goals).

---

## AI & Ethics Requirements

- AI recommendations must be **meaningful and contextual** — driven by the user's actual profile and log, not generic responses
- The app must be **transparent** that the AI is not a doctor
- User data must be **handled responsibly**
- The AI must have a **clear persona, tone, and safety rules** defined in its system prompt

---

## UI Requirements

- Must work for **at least two different types of users** (e.g. beginner and advanced)
- Must be **intuitive and easy to navigate**
- Layout and user flow should accommodate different fitness goals
